# SOC Projects Portfolio

This repository contains hands-on Security Operations Center (SOC) labs focused on log analysis, threat detection, and incident response using Wazuh SIEM.

The projects simulate real-world security monitoring and incident investigation workflows, demonstrating practical SOC skills in enterprise-like environments.

---

## Projects

### Project 1 — Windows Log Analysis & Privilege Escalation Detection

Collect and analyze Windows security logs to detect common security events such as failed logins, user creation, and privilege escalation.  

Folder: `Project-1-Wazuh-Windows-Incident`

### Project 2 — Brute-Force Attack Detection & Account Lockout Response

Detect brute-force login attempts and validate account lockout controls. Analyze authentication events and produce SOC-style incident reports.  

Folder: `Project-2-Wazuh-Bruteforce-Account-Lockout`

---

## Core Skills Demonstrated

- SIEM deployment, configuration, and monitoring  
- Windows Event Log analysis  
- Threat detection and alert triage  
- Privilege escalation identification  
- Account lockout and authentication monitoring  
- Incident documentation and reporting  
- Virtual lab environment setup and management  

---

## Repository Purpose

The goal of this repository is to showcase job-ready SOC analyst skills by simulating enterprise-style monitoring, detection, and response scenarios using Wazuh SIEM and Windows endpoints.
